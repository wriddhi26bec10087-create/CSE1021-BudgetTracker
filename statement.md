# Project Statement

## Problem Statement

many students and individuals find it difficult to keep track of their daily spending using complex financial apps that require internet access or paid subscriptions ,there is a need for a straightforward offline tool that runs fast on a basic computer terminal to log simple everyday transactions

## Scope of the Project

The project focuses on building a basic python command line application for tracking personal expenses, it includes creating a menu interface taking user input calculating totals and managing local file storage using a json file the scope is limited to local offline use and does not include a graphical user interface or cloud syncing features.

## Target Users

* college students managing their monthly allowance

* individuals looking for a simple distraction free way to track spending

* users who prefer working in a terminal or command line environment

## High Level Features

* set and update a total budget amount

* add new expenses with a short description cost and category.

* view a cleanly formatted text table showing all recorded expenses.

* save all user data locally to a json file so it persists between sessions.

* prevent the program from crashing when users type letters instead of numbers.
